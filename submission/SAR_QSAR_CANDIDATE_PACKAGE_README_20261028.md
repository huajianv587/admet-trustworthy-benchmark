# SAR/QSAR candidate package refresh - 2026-10-28

This archive is an author-review and preflight package for *SAR and QSAR in
Environmental Research*. It is not a submission receipt and does not certify
acceptance, independent external validation or zero total publication cost.

The package contains the refreshed title, author fields, declarations,
manuscript candidate, supplementary PDF, cover letter, release-boundary notes
and scientific status records. It deliberately excludes raw TDC data,
identity-level external prediction tables, model checkpoints and credentials.

The refreshed manuscript outputs are 19 pages for the main PDF and 3 pages for
the supplementary PDF. The package is a preflight bundle; the Word and PDF
files are generated from the same repaired manuscript text, but the final
portal preview remains the authoritative upload check.

Scientific boundary retained in all included records:

- broad confirmatory external matrix: `0/150 POWER_FAIL_HOLD`;
- descriptive external package: `150` artifacts (`120` traditional fits,
  `20` GIN prediction files, `10` Chemprop prediction files), not confirmatory;
- grouped cross-fit oracle sensitivity: retrospective, zero-retraining only;
- ExpansionRx: validation-only post-hoc diagnostic, not independent
  confirmation;
- focused CYP2D6: exploratory only because of prior test-role exposure.

Before upload, the author must complete the authenticated article-type,
subscription/non-OA and final fee checks, save the institutional category-level
JCR record, reconcile the exact AI tool/version/date disclosure, approve the
